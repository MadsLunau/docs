During setup, Parahelp asks you for three things: your **Zendesk URL**, the **login email** paired with your token, and a **Zendesk API token**. This guide shows where to get them. Parahelp sets up the webhook and triggers automatically, so there is nothing else to build in Zendesk.

2. Go to **Apps and integrations → APIs → API tokens**.

## 2. Pick the login email

The token is paired with a Zendesk login email. Parahelp signs in as that account, so its permissions decide what Parahelp can do.

- Use a real dedicated Zendesk agent account with its own email. We recommend `parahelp@yourcompany.com` or `<agent-name>@yourcompany.com`: a real user with a real mailbox, invited like any teammate, not an email alias. If your workspace requires an admin login for permissions, use a real admin email.
- Do not use a bot or machine user.

If the account doesn't exist yet, create it:

1. In **Admin Center**, click **People** in the sidebar, then select **Team → Team members**.
   <Frame>
     ![Image](/images/image-71.png)

   {/* SCREENSHOT: People > Team members */}
2. Click **Create team member**.
   <Frame>
     ![Image](/images/image-72.png)
   </Frame>
   {/* SCREENSHOT: Create team member */}
   {/* SCREENSHOT: Create team member */}
3. Enter the **Name** and **Email**, then click **Next**.
   <Frame>
     ![Image](/images/image-73.png)
   </Frame>
   {/* SCREENSHOT: Name and email */}
   {/* SCREENSHOT: Name and email */}
4. Under **Assign role**, select an agent role with the permissions below, or the **Admin** Support role if your workspace requires admin for these permissions.
   <Frame>
     ![Image](/images/image-74.png)
   </Frame>
   {/* SCREENSHOT: Assign role */}

   The account needs to be able to:
   - Read, search, export, create, and update tickets
   - Add public replies and internal notes
   - Update assignees, groups, status, priority, tags, and custom fields
   - Read and update users, requesters, and user fields
   - Read agents, admin users, groups, macros, brands, organizations, and ticket fields
   - Manage users, agents, and admins where the role exposes it
   - Create and manage webhooks and triggers
5. Click **Save**.

## 3. Note your Zendesk URL

Your Zendesk URL is the address you use to log in, for example `https://yourcompany.zendesk.com`.

## 4. Enter the values in Parahelp

Give Parahelp the three values when it asks:

- **Zendesk URL**
- **Login email** (the account from step 2)
- **API token** (from step 1)

Parahelp validates the token and creates the webhook and triggers automatically.

Afterwards, Parahelp will ask you to confirm which Zendesk agent acts as the support agent. Note: this can be a different account than the login email. The login email is what the token signs in as; the support agent is who replies on tickets.

Once connected, [assign tickets to Parahelp](/guides/zendesk-assigning).
