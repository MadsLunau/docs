You start a new task with a prompt. Each task has its own environment. Here, the Internal Agent can read and update configurations, build and run coding scripts, analyze support tickets, and test your Customer Agent. Once a task completes, you can review the work and result.

You can start a task in three ways:

- In the Platform on the "Tasks" tab.
- In Slack by tagging **@parahelp** in any channel where it's been added.
- Automatically, when an automation triggers (see [Automations](/platform/continuous-tasks)).

## Actions

When the Internal Agent suggests a change, such as a Customer Agent configuration update, a customer follow-up, or a new Linear issue, it lands in the "Actions" tab as a pending action.

Each action has one of these states:

- **Pending approval:** waiting for you to review.
- **Approved:** Once approved, the action will execute.

Admins approve and publish actions. Operators can draft and propose, but not approve. See [Settings](/platform/settings).

The Actions tab also shows all previously approved actions in the task, so you can see what's been approved and by whom.

## Visibility

Each task is either **private** or **shared**:

- **Private:** visible only to you. Use private tasks for personal exploration or work you're not ready to share.
- **Shared:** visible to everyone on your team. Use shared tasks for team-relevant work like Customer Agent configuration updates, customer follow-ups, or QA reports.

You can change a task from private to shared at any time.

## Connections

Each task has access to the tools you've connected on the [Connections](/internal-agent/tools) page. You can see which ones are active from the side panel. If a task needs a tool that isn't connected yet, the Internal Agent will prompt you to connect it.

## Files

Some tasks produce files, such as CSV reports, test definitions, or scripts. Files appear in the task side panel and can be downloaded.

## View activity

The "Tasks" tab shows everything you can access:

- **Your private tasks**
- **Your team's shared tasks** (which you can also continue)

Each task moves through states as work progresses:

- **Todo:** created and waiting to be started.
- **In progress:** the Internal Agent is working on it.
- **In review:** finished and waiting for your review.
- **Done:** reviewed and complete.

You can filter by:

- **Visibility:** private or shared.
- **Automations:** tasks started by a specific automation.
- **Creator:** tasks started by a specific teammate.
