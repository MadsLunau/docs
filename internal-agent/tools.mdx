The Internal Agent works with your tools through connections. Connect a service once, and it can use it as it completes tasks. Manage them all on the "Connections" page in Settings.

It uses connections in two ways:

- **Directly in tasks:** it calls a connected service while completing a task, like searching Linear for a known bug, posting a report to Slack, or writing a one-off script that pulls data from Stripe.
- **Building Customer Agent tools:** it writes scoped tools on top of a connection, like a refund tool built on Stripe, tests them, and stages them for your approval.

## Custom connections

- **MCP:** Connect any MCP server to give your agents access to the tools it exposes, like a custom CRM, a data warehouse, or internal scripts.
- **API:** Connect any service with an API, like Stripe, HubSpot, your own backend, or another third-party platform. The Internal Agent builds a tool that wraps the endpoint and tests it against real data before going live. For example, a "look up this customer in our internal admin panel" tool. To set one up, prompt the Internal Agent: tell it what to connect and what you want the agents to do with it. It guides you through wiring it up, requests any secrets it needs, and creates the matching tool or script.
