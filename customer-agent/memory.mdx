Memory files are the instructions your Customer Agent follows.

- **Persistent memory:** Instructions the Customer Agent follows on every ticket, like personality instructions.
- **Working memory:** Instructions the Customer Agent follows only for related tickets, like refund requests or billing issues instructions.

See your live memory files and their version history - who published what and when, with a diff for every change - on the [Configurations page in the app](https://app.parahelp.com/configurations).
